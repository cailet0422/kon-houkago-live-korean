♫설치 방법How to install

1원본 ISO 준비Get the original ISO

일본판 K-On! Houkago Live!! (Japan).iso. CSO라면 먼저 ISO로 풀어 주세요. 해시는 아래에서 확인.Japanese K-On! Houkago Live!! (Japan).iso. Decompress CSO back to ISO first. Hashes are below.

2패치 적용Apply the patch

패처에서 원본 ISO를 고르고 [패치]. 원본 확인 → 패치 → 검증이 자동으로 진행되고 K-On_Houkago_Live_KO.iso가 만들어집니다. (여유 공간 약 1.8GB)Choose the ISO in the patcher and press Patch. It verifies, patches and checks the result, creating K-On_Houkago_Live_KO.iso (≈1.8 GB free space needed).

3실행!Play!

PSP, 비타, PPSSPP 어디서든. 아래에서 기종을 골라 보세요. 일본판 세이브도 그대로 이어서 쓸 수 있어요.On PSP, Vita or PPSSPP — choose your platform below. Your Japanese save data keeps working.

  1. 커스텀 펌웨어(CFW)가 설치된 PSP가 필요합니다 (예: 6.60/6.61 + ARK-4, PRO-C, LME). PSP-1000/2000/3000/E1000/Go 모두 가능.
  2. USB 연결 또는 카드 리더기로 패치된 ISO를 ms0:/ISO/에 복사합니다. PSP Go 내장 메모리는 ef0:/ISO/. (2GB 이상 메모리 스틱)
  3. XMB의 게임 → 메모리 스틱에서 케이온! 방과후 라이브!! 실행.
  4. 실행되지 않으면 VSH 메뉴(SELECT)에서 ISO 드라이버(Inferno ↔ NP9660)를 바꿔 보세요.
  1. You need a PSP with custom firmware (e.g. 6.60/6.61 + ARK-4, PRO-C or LME). Works on PSP-1000/2000/3000/E1000/Go.
  2. Copy the patched ISO to ms0:/ISO/ via USB or a card reader. PSP Go internal storage: ef0:/ISO/. (Memory Stick ≥ 2 GB)
  3. Start 케이온! 방과후 라이브!! from Game → Memory Stick in the XMB.
  4. If it won't boot, switch the ISO driver (Inferno ↔ NP9660) in the VSH menu (SELECT).

잠깐! 「인스톨」은 꼭 OFF!Wait! Keep “Install” OFF!

게임 내 설정! 메뉴의 인스톨을 켜면 게임이 정상 동작하지 않아요. ISO 크기를 원본과 맞추느라 인스톨 데이터를 비워 뒀거든요. 기본값이 OFF이니 그대로 두면 됩니다.Turning on Install in the in-game 설정! (Settings) menu breaks the game — the install data had to be emptied to keep the ISO the same size. It is OFF by default, so just leave it.
